01 / BOUNDARY

宿主守住状态，扩展负责手艺

MyPaste 的边界很明确：历史、资产、偏好、密钥与剪贴板写入都属于宿主；扩展在独立进程里工作，只通过封闭的服务清单交换数据。安装时一次列清来源、进程形态、危险能力与网络目的地，之后只有一个启用/停用开关。

A / 01

按实体类型命中，不靠特判

一条剪贴板内容就是一个有类型的实体。注册表按 forms 裁决 0/1/N 个适配扩展，宿主不认识任何包 ID 或命令 ID，页面只回传宿主组合好的全局 ID。

resolve(entityType)text / image / fileclosed roles
mypaste.plugin.json§ 4.1
manifestVersion: 3
kind: "command"
commands: [{
  id: "format",
  forms: ["text"],
  placement: ["card-action"]
}]
A / 02

能力是封闭清单，不是通行证

扩展只能声明宿主已经实现的服务。第三方代码永不加载进宿主进程；页面不能直接访问数据库、文件系统或系统剪贴板，资产只经条目 ID 由宿主中介读取。

entity.readentity.savecopysecret.read

A / 03

安装即信任，来源只是标签

安装对话框一次说清风险，确认后不再逐项弹窗。目录按包记录 sha256 与仓库地址；安装记录的 publisher 只显示「由 MyPaste 组织发布」，不参与能力判断。宿主不钉住内容摘要，也不内嵌任何扩展。
